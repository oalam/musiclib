## Livre de référence

- **Blackwell, Cocker, Cox, McLean, Magnusson — *Live Coding: A User's Manual*** (MIT Press, 2022) — **open access CC-BY-SA**.
  - [→ MIT Press](https://direct.mit.edu/books/oa-monograph/5495/Live-CodingA-User-s-Manual)
  - [→ Version web TOPLAP](https://livecodingbook.toplap.org/)
  - **Nature du livre** : majoritairement théorique. Sections : Partial Histories (2), Expositions (3 — témoignages de 40+ praticiens, la partie la plus pratique), Notation (4), Liveness(es) (5), Time Criticality (6), What Does Live Coding Know? (7), What Does Live Coding Want? (8). **Pas de tutoriel code** : les auteurs disent explicitement "no how-to recipe book". Lire pour le cadre conceptuel, pas pour des recettes Tidal.
