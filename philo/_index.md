# philo/

Notes de réflexion. Quelques axes ouverts :

- **Live coding comme écriture située** — le code est performé, lisible, partageable. Qu'est-ce que ça change qu'on voie l'écriture pendant qu'elle sonne ?
- **Free party comme commun temporaire** — un sound system, un terrain, une nuit, une économie de don. Qu'est-ce qu'un commun éphémère ?
- **Algorithme et improvisation** — l'algorithme n'est pas le contraire de l'improvisation, c'est sa partition.
- **Autonomie et infrastructure** — free party = tout porter soi-même. Live coding = idem côté logiciel (open source, pas de DAW propriétaire). Symétrie à creuser.

À garder ici quand : ça analyse plutôt que ça raconte.
