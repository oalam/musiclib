# Sets de référence

Sets à étudier — non pour copier mais pour comprendre **comment ça se construit** : montées, transitions, gestion d'un long format, sound design, énergie. Pour chacun : ce qu'on en garde.

## Free tek / tribe historique

- **[69db (Spiral Tribe) — Live at Sterns Club, June 1993](https://www.mixcloud.com/69db/spiral-tribe-liveset-live-at-sterns-club-june-1993/)** — Acid tribal originel. Plateaux longs, pacing free party.
- **[69db — Live Set Dub IV (1997)](https://www.youtube.com/watch?v=T0HCSQDbFPM)** — Pont tribe → dub-acid. Pour les ouvertures hybrides.
- **[Heretik System — Moumouth (old school free party)](https://soundcloud.com/heretik-system/heretik-moumouth-old-school-free-party)** — Codes de la free tek FR, énergie 180+ BPM brute.

## Hardcore / industrial canon

- **[Manu Le Malin — Hardcore au corps, Astropolis 2011](https://www.youtube.com/watch?v=w2KEKMhhBIo)** — Construction d'un set hardcore live, gestion des montées.
- **[Manu Le Malin — DJ Set @ Hardcore Resurrection (Utrecht, 2003)](https://www.youtube.com/watch?v=0eBd3WN63nc)** — Industrial / hardcore canon, sound design saturé.

## Acid

- **[Ceephax Acid Crew — Boiler Room Manchester Live Set](https://www.youtube.com/watch?v=ep4-fFfEahE)** — Acid 303 hardware live, transposable en patterns Tidal.
- **[Ceephax Acid Crew — Live at 030303=17, Utrecht 2022](https://www.youtube.com/watch?v=Opd54XVSDc8)** — Improvisation acid sur synthés vintage, leçon de tension/relâche.
- **[Luke Vibert — Ransom Note Line Out #1 (last *I Love Acid* set)](https://archive.org/details/ransom-note-line-out-luke-vibert-live-mix)** — Acid hybride, transitions vers electro/breaks.

## Breakcore / IDM live

- **[Venetian Snares — Amµnition 2005 (Boiler Room 4:3)](https://fourthree.boilerroom.tv/film/v-snares/)** — Breakcore live, time signatures impaires. Trésor pour Tidal (`bd(3,8)`, `bd(5,11)`).
- **[Drumcorps — Live at Breakcore Gives Me Wood](https://soundcloud.com/drumcorps/live-at-wood)** — Hybride hardcore / breakcore guitare + breaks, sound design agressif.

## Dub techno

- **[Deadbeat ft. Tikiman — Boiler Room Berlin Live Set](https://www.youtube.com/watch?v=j8W8emgC3Y8)** — Dub techno live avec dub vocal. Pour les passages atmosphériques du set hybride.

## Live coding / algorave

- **[Alexandra Cárdenas — LIVECODERA (TidalCycles + SuperCollider)](https://www.youtube.com/watch?v=bzqBgQSyYz8)** — Référence directe. Écriture de patterns en temps réel.
- **[Renick Bell — Algorave Milan, 16th Generative Art Conference 2013](https://www.youtube.com/watch?v=MnXdj0BnVbc)** — Bass-heavy algorave, conduite d'un set algorithmique long.
- **[Kindohm (Mike Hodnick) — Live coding Tidal at Honey, Minneapolis 2015](https://www.youtube.com/watch?v=E_f1k7T8Gas)** — IDM / glitch live-codé, gestion d'erreurs en performance (très utile à regarder).
