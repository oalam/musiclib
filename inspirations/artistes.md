# Artistes / scènes à regarder

Liste vivante. Notes brutes au fil des découvertes.

## Algobabez

> Très bon exemple algorave.

Duo **Shelly Knotts + Joanne Armitage** (UK), actif depuis 2016. Travaillent en **SuperCollider** (pas Tidal), live coding très énergique, étiquetés "algo-pop".

- Bandcamp : https://algobabez.bandcamp.com/ — album *Burning Circuits* (2017)
- Label : [Fractal Meat](https://fractalmeat.bandcamp.com/) (Sheffield, scène commune avec Heavy Lifting)
- À chercher : sets ICLC / algoraves Sheffield sur YouTube

## Renick Bell

> Live coding très avancé.

Voir fiche dans [[penseurs-praticiens]]. Système personnel **Conductive** (Haskell), basé Tokyo/Berlin.

- Site : https://renickbell.net/
- Set repère : [Algorave Milan 2013](https://www.youtube.com/watch?v=MnXdj0BnVbc) (déjà dans [[sets]])

## Alex McLean

> Créateur de Tidal.

Voir fiche dans [[penseurs-praticiens]]. A.k.a. **Yaxu**. PhD Goldsmiths, a forgé le terme *algorave*.

- TidalCycles : https://tidalcycles.org/
- Site perso : https://slab.org/
- Blog Tidal (articles Yaxu) : https://blog.tidalcycles.org/author/yaxu/

## Shelly Knotts

Moitié d'Algobabez (ci-dessus). Live codeuse + chercheuse, travail sur l'improvisation algorithmique collaborative.

- Site : https://datamusician.net/
- À chercher : sets ICLC, projets solo

## Kindohm

**Mike Hodnick**. Live coding Tidal, IDM / glitch. Déjà mentionné dans [[sets]] et [[../refs/live-coding-ressources]].

- Chaîne YouTube : https://m.youtube.com/user/kindohm/videos
- Set repère : [Live Tidal à Honey, Minneapolis 2015](https://www.youtube.com/watch?v=E_f1k7T8Gas)

## Ryoji Ikeda

Compositeur japonais de minimalisme électronique **data-driven**. Pas live coding au sens strict, mais son travail sur les fréquences pures, le sub, les structures algorithmiques visuelles/sonores est une référence pour penser **algorithme + sensation pure** — utile pour les passages les plus tendus / minimalistes d'un set.

- Site officiel : https://www.ryojiikeda.com/
- Œuvres clés : *+/-* (1996), *Test Pattern* (2008), *Supercodex* (2013), *datamatics*, *superposition*
