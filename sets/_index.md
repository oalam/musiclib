# sets/

Brouillons de set, structures, captations.

Format proposé pour chaque set :

- date, lieu, durée
- structure macro (intro / montée / cœur / break / sortie)
- patterns clés réutilisables (lien vers fichiers `.tidal` dans `sets/patches/`)
- ce qui a marché, ce qui a foiré
- captation audio (lien externe, fichier dans `~/Music` plutôt qu'ici — ça pèse)
