# Music — live coding pour free party

Vault Obsidian d'apprentissage et de documentation.

**Intention** : apprendre le live coding avec [[technique/tidalcycles-bases|TidalCycles]] pour produire un set de 1 à 2h adapté à un sound system de free party. Terrain sonore : tribe / acid core hybride (180–200 BPM), avec ouvertures vers d'autres tempi et textures.

## Structure du vault

- `journal/` — entrées chronologiques datées (flux brut, voir [[journal/2026-05-10|dernière entrée]])
- `technique/` — apprentissage Tidal, synthèse, mix, sound system
- `digitakt/` — live sur Digitakt II : [[digitakt/doctrine|doctrine]] (grille des 16 tracks, banks, mutes, transitions)
- `sets/` — brouillons de set, structures, captations
- `inspirations/` — sets de référence, artistes, morceaux, ambiances qui nourrissent
- `refs/` — docs techniques, papers, talks, articles
- `fiction/` — fragments narratifs liés au projet
- `philo/` — notes de réflexion : live coding, free party, communs temporaires
